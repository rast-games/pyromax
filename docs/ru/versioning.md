# Версионирование документации

Документация начинается с версии **0.8** и использует `mike` для публикации нескольких сборок MkDocs в ветку `gh-pages`. Текущие исходники описывают **0.8.5**. Английская и русская версии собираются вместе для каждого выпуска.

## Локальный просмотр

```bash
uv sync --group dev
uv run mkdocs serve
```

## Публикация или обновление 0.8.5

```bash
uv run mike deploy --push --update-aliases 0.8.5 latest
uv run mike set-default --push latest
```

## Следующий выпуск

Обновите документацию вместе с исходным кодом, затем опубликуйте новую версию, не удаляя предыдущие снимки:

```bash
uv run mike deploy --push --update-aliases 0.9 latest
```

Повторный `mike deploy` с тем же номером заменяет снимок этой версии. Не редактируйте файлы в `gh-pages`: меняйте `docs/` в рабочей ветке и повторяйте deploy.
